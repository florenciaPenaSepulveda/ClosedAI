# ClosedAI

Proyecto ClosedAI. Para mantener buenas prácticas, el código se separó en repositorios independientes:

- [closedai-backend](https://github.com/florenciaPenaSepulveda/closedai-backend): API (NestJS).
- [closedai-app](https://github.com/florenciaPenaSepulveda/closedai-app): app móvil (Expo / React Native).
- [closedai-web](https://github.com/florenciaPenaSepulveda/closedai-web): frontend web.

Este repositorio se conserva como archivo histórico del proyecto original.
